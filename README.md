# 용마미식거리 · 먹거리·놀이·쉼 3D 마을

강릉 포남동 **용마미식거리**(2026yongma.com)를 3D 마을로 옮긴 시연 페이지입니다.
캐릭터로 입장해 실제 매대 명단 그대로의 먹거리 골목(부스 1~20번, 골목어게인 무대, 접객 파라솔, 운영본부, 바람길 쉼터)을 걷고,
게임장(게임·운세 기계, 인형뽑기, 미러포토 부스)과 절·교회·성당·놀이터·카페·식당까지 함께 둘러볼 수 있습니다.

- 시연 주소: https://whaleguard.github.io/yongma-land/
- 엔진·기능: 맥스데이 라이프(https://github.com/whaleguard/maxday-life) 공용 코드 사용 — 이 저장소는 이름·로고·공간 구성만 바꾼 진입 페이지
- 매대 정보: 「매대운영자명단 최종본」·「부스 배치도(최종)」 기준(공식 사이트 공개 정보, 개인정보 제외)
- 로고·마스코트(용지·마루): 포남용마거리 골목형상점가 상인회 / ㈜에스티엔미디어 자료
